# Notices

## The original mod

Bosses of Mass Destruction is by Barribob and miyo6032
(github.com/barribob/bosses-of-mass-destruction, formerly
github.com/miyo6032/bosses-of-mass-destruction), released under the
GNU LGPL v3.0 only. The boss names (Obsidilith, Lich, Gauntlet, Void Blossom)
and the idea of each boss's attacks come from it.

## What this port contains, and where it comes from

Nothing in this folder was copied or translated from the original mod or its
ports (CERBON's Forge/NeoForge port, FeskaXD's Fabric 26.3 port):

- **Code** (`mixins/bosses_of_mass_destruction/api/src/*.rs`): written new for
  Horizon's mod API. The attack cycles, timings and damage values are this
  port's own simplified design, not the original's Kotlin logic.
- **Models** (`model.rs`): original box geometry built in code. No GeckoLib
  `.geo.json` or animation file is used.
- **Textures** (`content/assets/.../textures/entity/*.png`): placeholder art
  generated by `tools/make_textures.py` (seeded noise, no source image).
- **Loot tables**: written new, with vanilla items only.
- **Lang**: the four names only.
- **Build and test scripts** (`tools/`): written for this port. The smoke test
  (`tools/vps/smoke.sh`) runs Horizon's own `horizon-engine` and
  `horizon-bots` on the operator's own prepared game files; none of those
  files are shipped here.

As of this version nothing from the original's code or assets has been added
(no LGPL-covered upstream file is included). Built and tested against Horizon
`a85af177a82504f357ff10d5d40d0b7230e2ac32` (native hooks API 415, game 26.3).

No NeoForge, GeckoLib or MultipartEntities code is used.

## Changes in this port

- Rewritten for Horizon's native mod API (Rust trait mod), not NeoForge; no
  Java, GeckoLib or MultipartEntities code is used or required.
- Attack cycles, timings, damage amounts and particles are a new, simplified
  design modelled on public descriptions of the bosses, not translated.
- Models are original box geometry built in code, with generated placeholder
  textures.
- Loot tables are new and use vanilla items only.
- Fights start from an altar (an offering used on crying obsidian), a
  mechanic of this port; the original's structures and spawning are not
  ported.
- The mod id `bosses_of_mass_destruction` and the four boss names are kept.
